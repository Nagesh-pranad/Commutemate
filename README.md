# CommuteMate+

## Problem Statement

Urban commuters in Bengaluru face daily challenges such as heavy traffic congestion, delayed transportation, and difficulty choosing the best travel option between metro and cab services. Users often switch between multiple applications to compare travel routes, fares, and estimated arrival times.

There is no unified platform that helps users efficiently plan their travel based on distance, time, and metro connectivity.

CommuteMate+ was developed to solve this problem by providing a smart and centralized commute planning system.

---

# Solution

CommuteMate+ is a smart commute planning web application built using Flask.

The application allows users to:

* Add travel events with source and destination locations
* Calculate travel distance using geographic coordinates
* Estimate cab fare and travel time
* Detect metro availability in Bengaluru
* Recommend the best transport option
* Predict the ideal departure time
* Redirect users to real services such as Ola, Uber, Rapido, Google Maps Transit, and Namma Metro

The system helps users save time and make smarter travel decisions.

# Setup Instructions

## 1. Clone the Repository

```bash
git clone https://github.com/yourusername/CommuteMate-Plus.git
```

---

## 2. Open the Project Folder

```bash
cd CommuteMate-Plus
```

---

## 3. Install Required Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run the Flask Application

```bash
python app.py
```

---

## 5. Open in Browser

Open the following URL in your browser:

```text
http://127.0.0.1:5000
```

# Usage

1. Enter event details including:

   * Event name
   * Source location
   * Destination
   * Date
   * Time

2. Click on **Add Event**

3. Select the event and click **Plan Commute**

4. The system will:

   * Calculate distance
   * Estimate travel time
   * Estimate fare
   * Detect metro availability
   * Recommend best transport option
   * Predict leave-by time

5. Users can continue booking through:

   * Ola
   * Uber
   * Rapido
   * Google Maps Transit
   * Namma Metro
